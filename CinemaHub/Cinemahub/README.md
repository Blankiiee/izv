# CinemaHub

Навчальна інформаційна система кінотеатру за матеріалами практикумів із візуального програмування SQL-запитів, генераторів і звітів.

## Запуск

Потрібен Python 3.10 або новіший. Сторонні пакети встановлювати не потрібно.

У PowerShell відкрийте каталог проєкту й виконайте:

```powershell
python server.py
```

Відкрийте у браузері <http://127.0.0.1:8000>. Щоб зупинити сервер, натисніть `Ctrl+C`.

## Можливості

- Огляд каси, денного розкладу та найпопулярніших фільмів.
- Фільмотека з пошуком, картками фільмів і додаванням, редагуванням та видаленням записів.
- Кінозали, їхня місткість, VIP-статус і статистика проданих місць.
- Розклад сеансів із перевіркою перетинання показів у межах однієї зали.
- Продаж квитків з унікальним місцем, статусом оплати й друкованою квитанцією.
- Навчальний SQL Query Builder із діаграмою таблиць, сіткою критеріїв, згенерованим SQL і результатами виконання.
- Готові SQL-сценарії: розклад, касові збори, заповненість залів, пошук за клієнтом і популярність покупців.
- Звіти про касу, зали та матрицю продажів за днем тижня й часом. CSV-експорт і друк.
- Україномовна довідка з практикуму та завантажуваний скрипт бази даних для Microsoft SQL Server.

## Дані

Після першого запуску застосунок створює локальну базу SQLite у `data/cinemahub.sqlite3` та додає тестовий каталог, розклад і квитки. Наступні запуски зберігають зміни.

У застосунку відкрийте **SQL-схема для MS SQL Server**, щоб завантажити `cinemahub.sql`. Скрипт розгортає навчальну схему `CinemaHub_DB` з таблицями `Genres`, `Halls`, `Movies`, `Sessions`, `Tickets`, зв’язками й початковими даними.
