# Квіз «Файлові системи»

Windows Forms застосунок (C#, .NET 8) — тест із 15 питань з обмеженням часу та оцінкою за 12-бальною системою.

## Склад проєкту

| Файл | Призначення |
|---|---|
| `QuizFileSystems.csproj` | файл проєкту |
| `Program.cs` | точка входу |
| `MainForm.cs` | головна форма: таймер, логіка тесту, підрахунок балів, оцінка |
| `Question.cs` | клас питання + база з 15 питань по темі |

## Як запустити у VS Code

1. Встанови **.NET 8 SDK** та розширення **C# Dev Kit**.
2. Відкрий папку проєкту у VS Code.
3. У терміналі виконай:

```
dotnet run
```

## Як зібрати .exe для архіву

Один самодостатній файл (не потребує встановленого .NET на іншому ПК):

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Готовий `QuizFileSystems.exe` буде тут:

```
bin\Release\net8.0-windows\win-x64\publish\QuizFileSystems.exe
```

Якщо .NET 8 на цільовому ПК уже встановлено, можна зробити легший варіант:

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

## Логіка роботи

- **Одна форма, зміна вмісту** — три панелі (`panelStart`, `panelQuiz`, `panelResult`) перемикаються через властивість `Visible`.
- **Timer** — `System.Windows.Forms.Timer` з інтервалом 1000 мс, 30 секунд на питання. При досягненні нуля показується повідомлення і відбувається автоперехід до наступного питання без зарахування балу.
- **Прогрес часу** — `ProgressBar`, колір підпису змінюється: зелений → жовтогарячий (≤10 с) → червоний (≤5 с).
- **Підрахунок балів** — за кожну правильну відповідь +1 бал (максимум 15).
- **Оцінка** — `бал = round(правильні / 15 × 12)`, діапазон 1–12.

### Шкала відповідності

| Правильних | Оцінка | Рівень |
|---|---|---|
| 15 | 12 | Високий |
| 13–14 | 10–11 | Високий |
| 9–12 | 7–10 | Достатній |
| 5–8 | 4–6 | Середній |
| 0–4 | 1–3 | Початковий |
