AidFlow — Windows-програма для управління запитами гуманітарної допомоги

Що вміє:
- додавати нові запити/завдання;
- редагувати, видаляти і перемикати статус виконання;
- шукати по назві, категорії або коментарях;
- сортувати за датою, пріоритетом, категорією або статусом;
- зберігати записи у базі SQLite;
- дивитися статистику по категоріях і кількості активних/завершених задач.

Як запустити:
1. Відкрийте папку VolunteerAidApp.
2. Запустіть файл run_app.bat або виконайте команду:
   python aid_tracker.py
3. У вікні програми введіть дані про запит допомоги, натисніть "Зберегти".

Кнопки:
- Зберегти — додає або оновлює запис.
- Очистити — очищає форму.
- Статус — перемикає виконання завдання.
- Видалити — видаляє вибраний запис.
- Пошук — фільтрує список за введеним текстом.

Програма створена на Python + Tkinter і працює на Windows без додаткового встановлення бібліотек.
